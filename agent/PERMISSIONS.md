# Permissions

## Free (no need to ask)
- Read and search any file in this repo.
- Create and edit files in `inbox/`, `daily/`, `ideas/`, `log/`.
- Add summaries and links.

## Ask first
- Deleting, moving or renaming existing files.
- Editing my notes in `courses/`, `projects/`, `knowledge/`.
- Running scripts, installing software, changing system settings.
- Sending messages or emails, or anything outward-facing.
- Touching SolidWorks or AutoCAD files. Work on copies only.

## Never
- Access password managers, banking or system folders.
- Delete originals or rewrite history in Git.
- Store secrets or personal ID data in this repo.
