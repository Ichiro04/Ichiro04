# Portfolio

One folder per finished project. Keep it honest and specific.

For each project record:
1. The problem and constraints.
2. The approach and the main design decisions.
3. The analysis: what was calculated, what was simulated, and how it was checked.
4. The result (numbers with units).
5. What went wrong and what I learned.
6. Images or drawings (stored outside Git if large).

A portfolio of 3-5 well explained projects is worth more than many shallow ones.
