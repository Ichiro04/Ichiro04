# Design checklist

## Requirements
- [ ] Function stated in one sentence
- [ ] Loads, speeds, temperatures, environment listed
- [ ] Required life and safety factor decided
- [ ] Applicable standards identified

## Design
- [ ] Load path is clear and direct
- [ ] Stress concentrations reduced (radii, gradual changes)
- [ ] Material chosen with a reason
- [ ] Fits and tolerances specified
- [ ] Assembly and disassembly possible
- [ ] Maintenance access considered

## Manufacturing
- [ ] Process chosen (machining, casting, sheet metal, 3D print, welding)
- [ ] Features suit that process
- [ ] Standard parts used where possible

## Verification
- [ ] Hand calculation for each critical part
- [ ] Simulation checked against the hand calculation
- [ ] Failure modes listed

## Documentation
- [ ] Drawing complete and checked
- [ ] Calculation sheet saved in the project folder
- [ ] Decisions recorded in the project README
